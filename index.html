wayne-anti 白名单机制 · 默认走代理

基于 sr_cnip_ad（国内外划分 + 广告过滤）的 Shadowrocket 配置：兜底 FINAL,proxy（未收录即走代理，fail-safe），只把国内网站挑出来直连；并置顶 Claude / Anthropic / Persona(KYC) 全域名强制代理。

用法

  • 方法一：用 Safari 或 Shadowrocket 扫描上面的二维码。
  • 方法二：Shadowrocket →「配置」→ 右上角 + → 把上面的 URL 粘贴进去 → 下载。
  • 导入后断开并重连一次，使规则生效。

DNS / WebRTC 防泄漏

  • DNS：走代理域名在节点侧解析，目标域名+IP 全在规则里就不漏；怕漏用白名单兜底 FINAL,proxy。验证：dnsleaktest.com。
  • WebRTC：小火箭（iPhone/iPad/macOS）：设置 → UDP → 禁用 STUN；验证：browserleaks.com/webrtc 只露节点 IP。

详细机制、STUN/UDP 说明见仓库 README。
